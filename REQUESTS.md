# Requests to the owner

Agents add requests here. The owner answers in `inbox/<project>/answers.md` (or drops files in `inbox/<project>/files/`) and says "كمّل".

Format:
```
## REQ-<number> | <project> | open
Need: <exactly what>
Why: <one line>
Put it in: inbox/<project>/files/<filename>
Answer in: inbox/<project>/answers.md under REQ-<number>
```
